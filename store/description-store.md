# PK Gmail — Simplify Style

## Français

**Nom** : PK Gmail — Simplify Style
**Accroche** : Gmail retrouve de l'espace.
**Résumé (≤150 caractères)** : Une interface Gmail plus claire : liste aérée, recherche centrée et réglages simples, avec vos messages dans Gmail.

**Description longue** : Une extension Chrome indépendante donne un peu d'air à Gmail : fond blanc, liste de messages centrée, catégories sobres, recherche discrète et conversation plus lisible. Choisissez une densité, une largeur, et les éléments de l'en-tête que vous souhaitez garder. Le bouton de rédaction flottant ouvre le composeur Gmail existant. Vos dossiers, actions, signatures et préférences de compte continuent de fonctionner dans Gmail. L'extension n'utilise pas l'API Gmail et n'envoie pas les courriels à un autre service. Réglages conservés dans le navigateur. Installation locale en mode développeur ; aucune publication Chrome Web Store n'est annoncée.

**Mots-clés** : Gmail, Chrome, boîte de réception, interface, courrier, lisibilité, confidentialité

**FAQ** :

- *Mes courriels passent-ils par un autre service ?* Non. L'extension ne fait aucune requête réseau ; Gmail continue de gérer les messages.
- *Comment essayer ?* Chargez `src/extension-simplify/` dans `chrome://extensions`, en mode développeur, puis rechargez Gmail.
- *L'extension est-elle au Chrome Web Store ?* Non. Elle est disponible comme source à charger localement.
- *Quelles fonctions de Simplify sont incluses ?* L'apparence et les réglages décrits ici. Bundles, rappels, fonds et blocage des traceurs ne sont pas inclus.

## English

**Name**: PK Gmail — Simplify Style
**Tagline**: Give Gmail room to breathe.
**Summary (≤150 characters)**: A calmer Gmail: an airy inbox, centered search and simple display settings, with your mail staying in Gmail.

**Long description**: A standalone Chrome extension makes more room in Gmail: a white background, centered message list, quieter category tabs, understated search and an easier-to-read conversation view. Choose a row density and list width, then keep or hide selected header elements. The floating compose button opens Gmail's own composer. Your folders, actions, signatures and account settings continue to work in Gmail. The extension does not use the Gmail API or send mail to another service. Display preferences stay in the browser. Install locally in developer mode; no Chrome Web Store listing is claimed.

**Keywords**: Gmail, Chrome, inbox, interface, email, readability, privacy

**FAQ**:

- *Does my email go through another service?* No. The extension makes no network requests; Gmail still handles your messages.
- *How can I try it?* Load `src/extension-simplify/` in `chrome://extensions` with developer mode on, then reload Gmail.
- *Is it on the Chrome Web Store?* No. It is available as source to load locally.
- *Which Simplify features are included?* The appearance and settings described here. Bundles, reminders, backgrounds and tracker blocking are not included.
