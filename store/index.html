Pour Gmail dans ChromeFor Gmail in Chrome

À charger en quelques étapes.A few steps to install.

L’extension est publiée sur le Chrome Web Store ; l’installation locale en mode développeur reste possible.The extension is live on the Chrome Web Store; local developer-mode install remains available.

  1. Téléchargez et décompressez le ZIP.Download and unzip the extension.
  2. Dans Chrome, ouvrez chrome://extensions et activez le mode développeur.Open chrome://extensions and turn on developer mode.
  3. Choisissez « Charger l’extension non empaquetée » et sélectionnez le dossier décompressé.Choose “Load unpacked” and select the extracted folder.
  4. Rechargez vos onglets Gmail ouverts et réglez l’affichage depuis l’icône de l’extension.Reload open Gmail tabs, then adjust the display from the extension icon.
Qu’est-ce qui change ?What changes?

Uniquement l’apparence des éléments Gmail repérés dans la page. Le bouton de rédaction appelle le bouton natif de Gmail. La note de confidentialité et les instructions complètes sont incluses dans l’archive.Only the presentation of detected Gmail interface elements changes. The compose button delegates to Gmail’s native control. The archive includes a privacy note and full instructions.
